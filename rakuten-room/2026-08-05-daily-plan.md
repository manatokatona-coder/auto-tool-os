### 楽天の商品ページが取れない理由（本日実測）

環境のネットワーク制限は解除されましたが、**楽天側が自動アクセスを遮断**しています。

- `item.rakuten.co.jp` へのHTTPリクエスト → 200を返すが**中身は42バイトの遮断ページ**（`Reference #18.ead6d717...`）
- ヘッドレスブラウザでの読み込み → `ERR_CONNECTION_RESET`
- 同じ環境から `example.com` や他社サイトは正常取得できるため、**環境側ではなく楽天側の制御**

したがって Day 1 と同様、**価格・送料・在庫・レビュー件数は「確認できません」と明記**し、推測値は一切記載していません。

### 解決策：Rakuten Developers の正しいURLが判明しました

先日「404で開けない」とご報告いただいた件、**本日ポータルにアクセスして正しい導線を特定できました。**

| 用途 | URL | 本日の応答 |
|---|---|---|
| ポータルトップ | https://webservice.rakuten.co.jp/ | ✅ 200 |
| **新規アプリ登録** | **https://webservice.rakuten.co.jp/app/create** | ✅ 302（ログインへ遷移＝正常） |
| 登録済みアプリ一覧 | https://webservice.rakuten.co.jp/app/list | ✅ 302（同上） |
| APIドキュメント | https://webservice.rakuten.co.jp/documentation | ✅ 200 |

ログインは楽天SSO（`login.account.rakuten.com`）経由です。**`/app/create` にアクセス → 楽天IDでログイン → アプリ登録**の流れで applicationId / accessKey / affiliateId が取得できます。

これが通れば、**本レポートの「確認できません」がすべて実データに置き換わります。**

| **報酬上限**：1商品1個につき1,000円まで／同一ユーザーは月3,000円まで | 高額商品1件を決めるより**低価格商品を幅広い人に**届けるほうが上限に当たりにくい。1,000〜3,000円帯中心の方針は構造と噛み合っている |
| **成果条件**：クリックから**24時間以内にカゴ追加**、カゴ追加から**89日以内の購入** | 「今すぐ検討する気になる」投稿が有利。**採寸が必要な商品は、その場でカゴに入りにくい**可能性がある。→ 下記の仮説3で検証 |

> 参考：報酬は楽天スーパーポイント（3,000円以下）／楽天キャッシュ（3,000円超）で支払われ、現金化は「直近3ヶ月毎月5,000ポイント以上」等の条件があり現実的ではありません。**収益は楽天経済圏内で使う前提**で計画してください。
> ※記事の更新は2024年4月です。料率・上限は変わっている可能性があるため、楽天アフィリエイトの公式ページで最新値をご確認ください。

### 現時点での仮説（成果データ未提供のため断定していません）

1. **8月上旬は「暑さ」と「帰省前の留守対策」が最も反応を取りやすい** → 本日の枠6（遮熱）・枠8（ランタン）、8/7〜8/8の防犯枠で検証
2. **クリックされやすい価格帯と購入されやすい価格帯は一致しない** → 1,000円未満は保存されやすく、3,000〜5,000円帯は検討期間が長い可能性。**投稿後7日の遅延コンバージョンを含めて計測**してください
3. **「採寸が必要」と明記した投稿はクリック率が下がるがコンバージョン率は上がる** → ただし上記の**24時間ルール**を踏まえると、採寸が必要な商品はその場でカゴに入らず成果を逃す可能性もある。本日は枠1・2・5・6・9が採寸必須、枠3・7・8・10が採寸不要。**この2群の成果差が最重要の観察対象です**
4. **夜20〜23時が最も反応が高い** → Day 1・Day 2 で同一時間割にしたため、2日分で比較可能

### 修正を行った箇所と理由

1. **枠3（防臭キャップ）**：初稿の「臭いが消えます」→「臭いの通り道をふさぐタイプ」に修正。防臭効果の断定を避け、構造の説明に留めるため。
2. **枠6（遮熱シート）**：初稿にあった「室温が下がる」という記述を削除し、「効果は窓の向きや住環境によって変わる」に修正。根拠のない数値・効果の断定を避けるため。
3. **枠9（フットレスト）**：「むくみが取れる」→「疲れの感じ方には個人差があります」に修正。健康効果の断定は指示14に抵触するため。
4. **枠5（珪藻土バスマット）**：「抗菌」はタイトル記載事項として候補表には残したが、投稿本文では効果を断定せず「清潔に保ちたい人が検討しやすい」に置換。
5. **枠8（LEDランタン）**：「停電に備えないと危険です」という不安を煽る表現を削除。指示16「ユーザーの不安を過度にあおらない」に抵触するため。
6. **枠10（バスブラシホルダー）**：Day 1のマグネットフックと訴求が近いため、文章を流用せず「掃除道具の定位置」という別の切り口で全文書き下ろし。指示16「投稿文を使い回さない」に対応。
7. **全枠共通**：紹介文から具体的な価格・送料の記載を削除し、商品ページ誘導に統一。価格を確認できておらず、古い価格を書くリスクがあるため。
