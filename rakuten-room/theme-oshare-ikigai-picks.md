## 規約・表現チェック

| 項目 | 結果 |
|---|---|
| 体験断定表現（愛用しています等）の不使用 | ✅ チェックリストは仕様紹介であり体験談ではない |
| 商品の弱点・確認事項を隠していないか | ✅ 各投稿末尾に「※」で軽い注意喚起を1行ずつ設置 |
| レビュー件数・評価点の事実記載 | ✅ 全件レビュー200件以上（差し替え前の候補で9件のみのものは不採用にした） |
| 「楽天1位」等の表記 | ✅ 商品タイトルに実際に記載されている場合のみ引用（#5） |
| 消耗品の除外 | ✅ 全6点とも繰り返し使えるインテリア・収納雑貨 |
| 価格帯 | ✅ 1,380〜3,300円で「安くて使い勝手がいい」の条件を満たす |
