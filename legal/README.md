# 法務ページのテンプレート

WordPressサイトを開設したら、固定ページとして以下の3つを設置してください。
いずれも一般的なひな形であり、法的助言ではありません。内容は必ず自分の運用実態に
合わせて書き換え、判断に迷う場合は専門家(弁護士等)に確認してください。

| ファイル | 用途 |
|---|---|
| `privacy-policy.md` | プライバシーポリシー(Cookie・アクセス解析・アフィリエイトの利用開示) |
| `about.md` | 運営者情報(サイトの目的、連絡先、コンテンツ生成方針の開示) |
| `ad-disclosure.md` | 広告・アフィリエイトに関する表示(ステマ規制対応。記事・SNS投稿の`[PR]`表記の根拠ページ) |

## なぜ必要か

- **A8.net / Amazonアソシエイト等の審査**では、多くの場合プライバシーポリシーの設置が
  求められます(申請前に設置しておくと審査がスムーズです)。
- **ステルスマーケティング規制**(景品表示法、2023年10月施行)により、広告であることが
  一般消費者に分かるように表示することが必須です。記事本文・SNS投稿の`[PR]`表記
  (`scripts/03_generate_article.py` / `scripts/07_post_to_social.py` が自動で付与)
  と合わせて、サイト全体の方針を示すページとして使ってください。

## 使い方

1. `[ ]` で囲まれた箇所(サイト名・運営者名・連絡先など)を自分の情報に置き換える
2. Markdownの内容をWordPress管理画面で固定ページとして作成・貼り付け
   (Markdown→HTML変換が必要な場合は `scripts/05_post_to_wordpress.py` の
   `markdown_to_html()` と同じ要領で `python -c "import markdown; ..."` を使うか、
   WordPress側のブロックエディタに直接貼り付けてください)
3. フッターメニュー等、サイト全体からリンクできる場所に設置する
4. 特定商取引法に基づく表記は、**自分自身が商品を販売する場合のみ**必要です。
   アフィリエイトリンクで外部サイト(楽天市場・Amazon等)に送客するだけの構成であれば
   基本的に不要ですが、判断に迷う場合は専門家に確認してください。
