# リサーチまとめ

このツールの仕様は、下の調査結果をそのままコードの制約に落としたもの。
数字や規約は変わりうるので、更新したときはここも直す。

---

## 1. 楽天ROOMの紹介文がどう読まれているか

### 文字数の制約が2つある

| 制約 | 数値 | 効き方 |
| --- | --- | --- |
| 紹介文の上限 | **500文字** | 超えるとシステムが受け付けず、投稿できない |
| 一覧・検索結果の表示 | **冒頭42文字** | ここまでしか出ない。クリックされるかはこの42文字で決まる |

→ ツール側の対応：500文字を超えたら後ろのブロックから自動で削る。1行目は42文字に収まる候補を優先して選び、収まらなければ画面上で警告する。生成結果には42文字の位置を色で示す。

### 実際に伸びている投稿の並び

伸びているルーマーの投稿を分解すると、文章の巧拙より「見た目の型」が揃っている。
実例（479文字）はこの並びだった。

| 位置 | 要素 | 例 |
| --- | --- | --- |
| 1 | キャッチ | `毎日使いたくなるタンブラー🤎大容量で可愛すぎた…🥹` |
| 2 | 署名タグ | `#ちぇる。オリ写⸜❤︎⸝` |
| 3 | 誰向けか | `🥤見た目も機能性もどっちも欲しい人に` |
| 4 | 区切り線 | `- - - - - - - - - - - -` |
| 5 | ✔リスト | `✔ 保冷・保温OKで飲み頃キープ🤎` を6行 |
| 6 | 体験（短い段落） | 2〜4行の段落を空行で区切って3〜4本 |
| 7 | 誘導文 | `詳しくは 〘 楽天市場で詳細を見る 〙 をクリックしてください🎀𓂃𓈒𓂂𓏸` |
| 8 | タグ | `#オリジナル写真 …（8個）… 暑さ対策 車内を快適に` |

読み取れる工夫がいくつかある。

- **1行目に商品名と感情**。悩みの提示から入らず、`{形容}{商品名}{絵文字}{感情}` で組む。実例は25文字で、42文字の表示枠に収まっている
- **署名タグ**（`#◯◯オリ写`）で自分の投稿をまとめている。`#オリジナル写真` とは別に、本文の上部に置く
- **絵文字の色味を揃える**。実例は🤎で統一し、商品のブラウンと写真に馴染ませている
- **✔の飾りは全行には付けない**。付いている行と付いていない行が混ざっていて、機械的に見えない
- **体験は短い段落に割る**。1段落2〜3行で、空行を挟む。スマホでの見た目が軽くなる
- **タグは8個**。そのうえで末尾2語は `#` を付けない平テキストにしている。ROOMの検索には当たるが、読み手をタグ一覧へ逃がさない
- 区切り線（47文字）とタグ行（71文字）だけで全体の1/4を使う。あふれたときは飾りから削るのが理にかなう

→ ツール側の対応：この並びをそのまま「インフルエンサー型」として実装した。既定の型にしている。
✔の飾りは空文字を混ぜて散らし、体験メモは空行で段落に割る（文字は一切いじらない）。
500文字を超えたら 区切り線を短く → 平テキスト → ✔を後ろから → 体験段落 → タグ の順に削る。

### 紹介文の骨格は3段構成

人気ルーマーの紹介文はほぼ例外なくこの形をしている。

1. **イントロ（つかみ）** — 商品を短く提示し、読み手の潜在的な悩みに語りかける
2. **メイン（納得させる）** — メリット、使用シーン、そして**デメリットも書く**。デメリットは対処法とセットで書くと信憑性が上がる
3. **クロージング（行動）** — 買ったあとに生活がどう変わるかを想像させる

補助的に効くとされているのが、
- 適度な改行・箇条書き・強調で読みやすくする
- オリジナル写真と、自分の体験に基づく具体的な記述
- 完璧な文章より、テンポよく投稿し続けること

→ ツール側の対応：この3段をそのままテンプレートの構造にした。「正直なデメリット」は入力必須級の扱いにして、文体ごとに対処法を添える言い回しを用意している。体験メモは加工せずそのまま本文へ入れる（ここが唯一のオリジナリティなので機械が触らない）。

### ランクとピックアップ欄

- ROOMランクは S / A / B / C / D / E の6段階。前月末23:59に確定し、当月1日8:00に反映される
- **B以上でランクボーナス**が付く（B: +1%、A: +2%、S: +3%）
- **Bランク以上になるにはオリジナル写真の投稿が必須**
- ピックアップ欄は毎週金曜更新。掲載されているのはすべてオリジナル写真の投稿で、検索順位といいね数も条件に絡む

→ ツール側の対応：「自分で撮った写真を使う」チェックで `#オリジナル写真` の付与を切り替える。ONが既定。

### 投稿（コレ！）の上限

1時間100回 / 24時間200回 / アカウント通算20,000回。
→ 一括大量生成のような機能はあえて付けていない。上限に当たる使い方は事故のもとなので、1件ずつ作って投稿する導線にしている。

## 2. ハッシュタグ

- ROOMで最も使われているタグは **#オリジナル写真**
- 季節・イベントのタグはピックアップ欄に並びやすい（冬＝加湿器・福袋、春＝新生活・花粉、夏＝暑さ対策・涼感寝具、秋＝防災・あったかグッズ）
- 検索キーワードすべてに `#` を付ける付け方は逆効果。読み手がタグ側の一覧へ流れて、元の投稿から離脱する（いわゆる「自爆タグ」）
- **投稿内容と関係のない人気タグを入れる行為は、楽天アフィリエイトの禁止事項**

→ ツール側の対応：ROOMは5個、Xは3個を既定の上限にした。付ける順番は「オリジナル写真 → イベント → カテゴリ → 季節 → 基礎タグ」で、枠が埋まったら切る。

## 3. X（旧Twitter）側

### 文字数の数え方

Xの上限は「重み付き280」で、文字種によって重みが違う。

- 日本語などの全角文字：1文字あたり **2**
- 半角英数など（U+0000–U+10FF ほか）：1文字あたり **1**
- **URLは実際の長さに関係なく一律23**（t.coで短縮されるため）
- 絵文字の合字（👨‍👩‍👧‍👦 など）はまとまりで2

つまり日本語だけなら140文字だが、URLを1つ入れると実質128文字ぶんに減る。

→ ツール側の対応：この規則をそのまま実装して、投稿前に正確な残量を出す。280を超える場合はタグ→箇条書きの末尾の順に自動で削り、1行目のフックは最後まで残す。

### 投稿の作り方

- ハッシュタグは前後に半角スペース。数を積むより関連性。無関係なタグを大量に付けるとエンゲージメントが下がる
- セールの公式タグ（例：`#楽天スーパーSALEで買うべきもの`）は**公式発表直後の初動が最重要**で、1〜2日目が勝負
- 動画付きのポストは通常投稿よりインプレッションが伸びやすい
- 毎日何度も投稿するとスパム判定のリスクがある

→ ツール側の対応：共感型 / 悩み解決型 / スペック提示型 / セール速報型 / まとめリスト型の5つを型として用意した。

## 4. 規約とステマ規制

### ステマ規制（景品表示法・2023年10月施行）

**PR表記が必須になるケース**
- 楽天や広告主から商品の提供を受けた（プレミアムパートナー等）
- 楽天や広告主のイベント・体験に参加した
- アフィリエイター向けのお試しクーポンを使った
- その他、成果報酬以外の金品や情報のやり取りがあった

**任意でよいケース**
- 自分で買った商品を、アフィリエイトリンクで紹介するだけ

**表記に使える言葉**：「PR」「広告」「宣伝」「プロモーション」「本ページはプロモーションが含まれています」
**使えない言葉**：「AD」「sponsored」「Premium partner」（日本語話者に伝わらないため）

**置く位置**：X・楽天ROOMともに**投稿の上部**。一般消費者が認識しやすい大きさ・色・位置であること。

### 2025年8月の楽天アフィリエイト規約改定

**他人の投稿への返信（リプライ）やコメント欄にアフィリエイトリンク等を掲載する行為が禁止事項として追加された。**
自分の投稿へのセルフリプはこれに当たらないが、他人の投稿には貼らない。

→ ツール側の対応：PR表記のチェックを標準搭載し、必須ケースの選択肢を画面に出す。リンクの置き方に「セルフリプ」を選んだときは、この規約の注意文を必ず一緒に表示する。

### 値引きの書き方（二重価格表示）

「通常価格19,800円 → 9,900円」のように2つの価格を並べる書き方は**二重価格表示**と呼ばれ、
比較に使う価格が実態と違うと景品表示法の不当表示にあたる。

消費者庁の価格表示ガイドラインでは、比較対照価格として使える「最近相当期間にわたって販売されていた価格」は、
**セール開始直前8週間のうち4週間以上、その価格で販売されていた**ことが原則とされている
（販売開始から8週間に満たない商品は、販売期間の過半）。

つまり、自分で見積もった価格や、実際には売られていなかった価格を「通常価格」として書くのはNG。

→ ツール側の対応：通常価格とセール価格の2欄を用意し、入力された値からしか価格表記を作らない。
割引率は**切り捨て**で計算する（四捨五入だと49.6%が50%になり、値引き率を実態より大きく見せてしまうため）。
通常価格とセール価格が逆なら要修正として弾き、割引率が90%以上なら桁の入力ミスを疑う注意を出す。
「通常価格は商品ページの表示をそのまま写す」旨を入力欄の直下に常時表示している。

### 表現面のNG

| 分類 | 例 | 理由 |
| --- | --- | --- |
| 薬機法 | 治る、治療、痩せる、免疫力、熱中症、花粉症 | 医薬品的な効能効果の標榜。疾病名は特に危ない。「熱中症」はROOMで弾かれる報告が多い |
| 景品表示法 | 最安値、日本一、No.1、絶対、必ず、100% | 根拠のない最上級・断定表現 |
| ROOM規約 | 転売、せどり、利益、仕入れ、買取、相互フォロー、フォロバ | 転売の示唆と、相互フォロー勧誘 |

その他、他人の投稿のコピペ、ブランド名を出した比較表現もNG。

→ ツール側の対応：27件の辞書にして、生成物と貼り付けたテキストの両方を検査する。指摘には理由と言い換え案を必ず付ける。

## 5. 楽天のセールと、一人暮らし層の題材

### セールの周期

| イベント | 周期 | 備考 |
| --- | --- | --- |
| 楽天スーパーSALE | 3・6・9・12月 | 半額商品が出る。買い回りでポイント最大10倍 |
| お買い物マラソン | 月2〜3回 | スーパーSALEの月は後半に1回のことが多い |
| 5と0のつく日 | 毎月5・10・15・20・25・30日 | 楽天カード決済でポイントアップ。毎回エントリーが必要 |

日付まで確定できるのは「5と0のつく日」だけなので、ツールでは**確定と傾向を必ず区別して表示する**（推測を断定として出さない）。

### 一人暮らし層が抱えている具体的な悩み

調査で繰り返し出てくるもの。紹介文のイントロは、ここに当てるほど刺さる。

- キッチンが狭い（一人暮らしの料理環境の悩みで最多、44.9%）
- 自炊できない理由の筆頭は「時間がない」
- 収納が足りない／壁に穴を開けられない
- 部屋干しが乾かない・生乾き臭
- 隣室の生活音（話し声 33.9%、足音 21.1%）
- コンセントの数が足りない
- 体調が悪くても家事を代われる人がいない
- 災害・防犯の備えを後回しにしている

### 商品の切り口は3層で持つ

| 層 | 性質 | 例 |
| --- | --- | --- |
| 王道 | 検索数が多いが競合も多い | コードレス掃除機、ミニ炊飯器、電気毛布 |
| 知る人ぞ知る | 差がつきやすい | 縦型トースター、突っ張り棚、流せるトイレブラシ |
| マニアック | 競合が少なく、刺さる人には強く刺さる | ペットボトル米びつロート、隙間ワゴン(幅15cm)、排水口ヘアキャッチャー、半熟たまごメーカー |

→ ツール側の対応：61件の商品辞書に、この3層と季節・悩み・訴求・デメリットまで持たせた。ネタ出しは「季節 × カテゴリ × この3層」で絞れる。
