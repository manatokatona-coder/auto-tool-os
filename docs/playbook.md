# 運用の手順書

ツールの使い方ではなく、「毎日どう回すか」の話。
文章を作るところは自動化できたので、残る仕事は**写真と体験メモ**と**投稿のタイミング**の2つ。

---

## 毎日のルーティン（15〜20分）

1. **ネタを決める（2分）**
   「ネタ出し」タブで季節とマニアック度を選んで出す。
   その日にセールがあるなら、セール向きのカテゴリ（家電・寝具・まとめ買い）に寄せる。

2. **写真を撮る（5分）**
   ここだけは代わりがきかない。ROOMのランクB以上（＝報酬ボーナス）とピックアップ欄の掲載は、
   どちらもオリジナル写真が条件になっている。

3. **体験メモを1〜2行書く（3分）**
   「3週間使ったら洗濯のストレスがほぼ消えた」程度でいい。
   ここが他人の投稿との差になる部分なので、ツールは加工せずそのまま本文に入れる。

4. **紹介文を生成してコピー（1分）**
   3パターン出るので、42文字の色が付いた範囲を読んで、一番引きが強いものを選ぶ。

5. **ROOMに投稿（2分）**

6. **X用の文を生成して投稿（3分）**
   ROOMの投稿URLを「X投稿」タブのリンク欄に貼ってから生成する。

## セールのときだけやること

### 開催の2〜3日前

- 公式のセールタグが出たら**すぐ**押さえる。初動の1〜2日目が勝負で、後から乗ると埋もれる
- 紹介したい商品の投稿を先に作っておく（セールが始まってから書き始めると出遅れる）
- エントリーは開始の1〜2日前から始まることが多い

### 開催中

- 「セール速報型」で初日に投げる
- 中日に「まとめ投稿（リスト型）」でテーマ別にまとめる
- 5と0のつく日がセール期間と重なる日は、ポイント倍率の話を入れると反応が変わる

### やらないこと

- 1日に何度も同じような投稿を投げる（スパム判定のリスク）
- 投稿内容と関係のない人気タグを付ける（楽天アフィリエイトの禁止事項）
- 他人の投稿のリプ欄にリンクを貼る（2025年8月の規約改定で明確に禁止）

## セール商品を書くとき

「商品タイプ」を**セール商品**にして、通常価格とセール価格を入れる。
冒頭が価格の変化から始まるので、一覧に出る42文字の中で「安くなっている」ことが伝わる。

入力するときの決まりごとはひとつだけ。

**通常価格は、楽天の商品ページに出ている価格をそのまま写す。**

自分で「だいたいこのくらいだった」と見積もった価格を書くと、景品表示法の不当な二重価格表示になる。
比較に使ってよいのは、セール直前8週間のうち4週間以上その価格で売られていた価格が原則。
商品ページに二重価格の表示がない商品は、価格欄を空にして「割引率%」だけ入れるか、通常商品として書く。

値引き率が中途半端（20〜30%台）の商品は、価格の変化より悩みの共感から入ったほうが伸びることもある。
その場合は通常商品として書いて、価格は本文の後半に回す。

## 文体の使い分け

| 文体 | 向いている場面 |
| --- | --- |
| ゆるふわ共感 | フォロワーとの距離が近いアカウント。日用品・雑貨 |
| 丁寧レビュー | 単価の高い家電。信頼を積み上げたいとき |
| リアル辛口 | 好みが割れる商品。デメリットを先に出して信憑性を取る |
| ミニマル箇条書き | スペックで決まる商品。スクロールの速いタイムライン |
| 時短・効率 | 働きながら一人暮らしをしている層向け |

同じ商品でも文体を変えて別日に投稿すると、届く相手が変わる。

## 数字の見方

ROOMのアフィリエイトレポートで見るのはこの順番。

1. **クリック数** — 42文字のフックが効いているか
2. **クリック率** — 写真が効いているか
3. **成果** — 商品選びが合っているか

クリックが取れているのに成果が出ない商品は、紹介文ではなく商品側の問題（価格・レビュー・在庫）。
クリックが取れていない商品は、42文字を書き直す。

---

## 手が回らないときの優先順位

1. オリジナル写真（ランクボーナスとピックアップ欄の前提条件）
2. 冒頭42文字（一覧でここしか見えない）
3. 正直なデメリット（信頼と再訪につながる）
4. ハッシュタグ（最後。付けすぎは逆効果）
