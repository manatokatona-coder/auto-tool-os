## デザインについて

**実店舗の外観写真が確認できなかった**ため、林商会様のLP（`cleaning-lp/hayashi-shokai/`）のように店頭ビジュアルに直接合わせる形は取れませんでした。代わりに、リサーチで判明した「方南銀座商店街にある、昔ながらの手仕上げ専門店」という店の性格から配色とモチーフを組み立てています。

- **配色** — 藍（`--indigo` #24405E）を主役に、木の看板を思わせる飴色（`--wood` #A9754A）、職人の朱肉印を思わせる紅（`--hanko` #A5362D）を差し色に。地の色は経年した和紙のような温かいクリーム
- **書体** — 見出しは明朝（Hiragino Mincho → Yu Mincho → Noto Serif JP）。手仕上げ専門店の落ち着きに合わせています
- **モチーフ** — ヒーローに「手仕上／仕上済」の朱印（はんこ）バッジを配置。しみ抜き・手仕上げという実際の強みを、職人の検品印というモチーフに翻訳しました
- **背景** — ごく淡い縦縞（暖簾を思わせるパターン）を全面に敷いています

**もし実店舗の外観写真をお持ちでしたら、それをもとに配色・モチーフを実物に合わせて調整できます。**

## 構成

ヒーロー／選ばれる理由3点／料金・ご相談（金額は要問い合わせ導線）／ご利用の流れ3ステップ／店舗情報／FAQ 4問／クロージングCTA。集荷・宅配サービスの有無が未確認のため、林商会様版にあった「集荷・お届け」セクションはこの版には含めていません。

## 差し替えるところ

- 営業時間・定休日（`#shop` の表、および `.hero-note` の一次確認前の注記）
- 料金（現状は「お問い合わせください」導線のみ。金額が分かれば料金表セクションを追加できます）
- 駐車場・支払い方法・宅配サービスの有無
- フッターの注意書き（実店舗確認後に削除）
- 可能であれば実店舗の外観写真

配色を変える場合は `:root` の `--indigo` / `--wood` / `--hanko` を書き換えれば全体に反映されます。
