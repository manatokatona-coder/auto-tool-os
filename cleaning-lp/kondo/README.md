## デザインについて

初版は林商会様版（`cleaning-lp/hayashi-shokai/`）と骨格が似すぎていたため、実在する有名クリーニングチェーン（白洋舍・ポニークリーニング・リネット・リナビス・せんたく便など）のLP構成をリサーチし、レイアウトの骨格から作り直しました。カードグリッド・アイコンタイル・シャツ+アイロンのイラストといった、林商会様版と共通していた要素は使っていません。

- **配色** — 地の色を白に。藍（`--indigo-deep` #13253B）をヒーロー・料金案内・店舗情報・フッターの背景に面で使い、クリーニング業界で信頼感の定番とされる「青×白」を、他社にありがちな水色ではなく深い紺で表現しています。差し色は真鍮色の金（`--gold`）、しみ抜きの実績を象徴する朱（`--hanko`）はお客様の声の引用符のみに使用
- **書体** — 見出しは明朝（Hiragino Mincho → Yu Mincho → Noto Serif JP）
- **お客様の声（新規セクション）** — エキテンに実際に寄せられた「昔ながらの店舗、しみ抜きが丁寧。」という口コミを、出典リンク付きでそのまま引用。林商会様版にはなかった、大手クリーニングLPでよく使われるセクションです
- **料金案内** — レシート（伝票）のようなギザギザの縁を持つ紺のパネルで表現。カード＋ボタンの並びではなく、実店舗の「値札」を思わせる形にしました
- **ご利用の流れ** — カードの羅列ではなく、線でつながった円環（タイムライン）で表現
- **店舗情報** — 白カード2枚ではなく、紺一枚の案内板に統一
- **ヒーロー** — イラストの代わりに、背景に大きく沈めた「巧」の一字を配置

## 構成

ヒーロー／お客様の声／こだわり3点（横一列）／料金・ご相談（金額は要問い合わせ導線）／ご利用の流れ3ステップ（タイムライン）／店舗情報／FAQ 4問／クロージングCTA。集荷・宅配サービスの有無が未確認のため、林商会様版にあった「集荷・お届け」セクションはこの版には含めていません。

## 差し替えるところ

- 営業時間・定休日（`#shop` の表、および `.hero-note` の一次確認前の注記）
- 料金（現状は「お問い合わせください」導線のみ。金額が分かれば料金表セクションを追加できます）
- 駐車場・支払い方法・宅配サービスの有無
- フッターの注意書き（実店舗確認後に削除）
- 可能であれば実店舗の外観写真

配色を変える場合は `:root` の `--indigo-deep` / `--gold` / `--hanko` を書き換えれば全体に反映されます。
