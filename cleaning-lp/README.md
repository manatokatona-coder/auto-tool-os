# クリーニング店 LP

街のクリーニング店向けの、1ファイル完結のランディングページです。
ブラウザで開くだけで表示できます（ビルド不要・外部リソースなし）。

| ファイル | 用途 |
| --- | --- |
| `index.html` | 汎用テンプレート（架空店舗のサンプル） |
| `hayashi-shokai/index.html` | クリーニング林商会（杉並区松庵）向けのご提案用デザイン案 |

## hayashi-shokai/ について

実在店舗への提案用に、公開情報をもとに内容を差し替えたものです。**店舗様の確認を受けたものではありません。**

反映済みの公開情報 — 店名・住所（松庵2-1-21）・電話（03-3333-6256）・営業時間（月〜土 8:00〜19:00、祝日 9:00〜19:00、日曜定休）・アクセス（三鷹台 徒歩11分／久我山・西荻窪 徒歩12分）・石けん洗い／手仕上げ／集荷・お届け・理念文。

**未確認のため意図的に載せていないもの** — 具体的な料金、創業年、写真、駐車場、支払い方法、しみ抜きや保管の可否。料金セクションは金額を書かず「お問い合わせください」の導線にしてあります。料金表を載せる場合は、`index.html` の `#price` にある `.price-top` / `.tables` ブロックを移植して実際の価格を入れてください（該当箇所にHTMLコメントを残しています）。

公開前に、店舗様に内容の確認と差し替えを必ず依頼してください。フッターにその旨の注記を入れてあります。

### デザイン（テンプレートとの違い）

「石けんと手仕事」をコンセプトに、テンプレート（`index.html`）とは別の視覚言語を与えています。

- **配色** — オリーブ石けんの緑（`--soap` #7E9459）／藍（`--btn-bg` #2E4A5C）／麦色（`--sun` #DCC79A）。グラウンドは洗い上がりを思わせる青みの白。テンプレートのティール＋バターイエローとは別系統です
- **書体** — 見出しを明朝（Hiragino Mincho → Yu Mincho → Noto Serif JP）に変更し、字間・行間を広めに。手仕事の店の落ち着きを出す狙いです。UIと本文はゴシックのまま
- **フォルム** — 角丸を控えめに（パネル 22px／カード 14px）。フッターは藍のベタ塗りで、暖簾のように全体を締めています
- **モチーフ** — ヒーローの泡は画面下部に寄せて「洗い桶に立つ泡」に。イラストに固形石けんを追加。アイコンは石けん・アイロン・集配の線画に描き直し

## デザイン

- 配色は「石けんの泡と天日干し」をイメージした淡いティール＋バターイエロー。
  すべて CSS カスタムプロパティ（`:root`）で定義しています。
- 見出しは丸ゴシック系のフォントスタックで柔らかい印象に。欧文・数字は別スタック。
- ライト／ダークの両テーマに対応（OS設定に追従）。
- ヒーローのイラスト・地図はインラインSVG、泡のアニメーションは Canvas。
  `prefers-reduced-motion` を指定している環境ではアニメーションは停止します。

## 差し替えるところ

掲載情報はすべて架空のサンプルです。実店舗で使う場合は以下を差し替えてください。

- 店名・ロゴ（`.brand` / `<title>` / `meta[name=description]`）
- 電話番号（`href="tel:0120000000"` と表示テキスト、計5か所）
- 住所・アクセス・営業時間・定休日・駐車場・支払い方法（`#shop`）
- 料金表（`#price`）／取扱い品目（`#service`）
- 簡易地図（`.map` の SVG）は、Google マップ等の埋め込みに置き換え可能です
- フッターの注意書き（サンプルである旨）を削除

配色を変える場合は `:root` の `--soap` / `--sun` などを書き換えれば全体に反映されます。
ダークテーマ用の値は `@media (prefers-color-scheme: dark)` と `:root[data-theme="dark"]` の
2か所に同じ値を定義しています。
