## デザインについて

ご依頼は「今どきの凝ったデザインで、トレンドになりそうなもの」でした。林商会様版（暖色・実店舗写真ベース）、近藤クリーニング様版（白×藍・伝統チェーン準拠）とは異なる方向性として、2026年のWebデザイントレンド（ベントーグリッド、グラスモーフィズム、オーロラ／メッシュグラデーション、キネティックタイポグラフィ）を参考に、SaaS/スタートアップ系サイトに近い構成で作成しました。

- **配色** — 白地に、紫（`--violet`）×ミント（`--mint`）のグラデーションを差し色として使用。CTAやアイコン、見出しの一部にグラデーションをかけ、深紺（`--dark`）のセクション（表彰・CTA）で締まりを出しています
- **ヒーロー** — 背景にぼかしたグラデーションの光彩（オーロラ）を配置し、見出しの一部をアニメーションするグラデーションテキストに
- **お知らせティッカー** — 確認済みの強み（表彰・シミ抜き・組合加盟など）を横スクロールする帯で常時表示
- **ベントーグリッド** — 「選ばれる理由」を大小非対称のカードで並べる、2025〜2026年のトレンドであるBento UIを採用
- **実績スポットライト** — 「杉並区技能功労者表彰」という確認済みの実績を、濃紺のグラスモーフィズムカードで大きく紹介
- **アクセス** — 白カードの案内板＋グラデーションのマップカードの2枚組。営業時間は要確認の注記付き
- **スクロール演出** — IntersectionObserverによるスクロール連動のフェードイン（JS無効時・reduced motion環境ではアニメーションなしで即時表示）

## 構成

ヒーロー／強み帯（ティッカー）／選ばれる理由（ベントーグリッド4枚）／実績スポットライト（技能功労者表彰）／アクセス・店舗情報／よくある質問4問／クロージングCTA。料金・集荷宅配サービスの有無が未確認のため、料金セクションと集荷・お届けセクションは含めていません。

## 差し替えるところ

- 営業時間・定休日（`#access` の案内板、および `.caution` の注記）
- 料金（現状は「お電話でご相談ください」導線のみ）
- 駐車場・支払い方法・宅配サービスの有無
- フッターの注意書き・名称注記（実店舗確認後に削除）
- 可能であれば実店舗の外観写真

配色を変える場合は `:root` の `--violet` / `--mint` / `--coral` / `--dark` を書き換えれば全体に反映されます。
