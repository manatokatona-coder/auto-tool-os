## デザインについて（v2：リネット参考版）

初版は「今どきの凝ったデザインで、トレンドになりそうなもの」というご依頼のもと、ベントーグリッド／グラスモーフィズムのSaaS系デザインで作成しましたが、続けて「宅配クリーニングのリネット（lenet.jp）のサイトを参考に作り直してほしい」というご依頼をいただき、v2として構成から作り直しました。

**参考にした情報について** — このサンドボックス環境からは `lenet.jp` への直接アクセスが同一セッション内で確認できず（WebFetch・curlともに403でブロック）、実際の画面を1px単位で確認することはできませんでした。そのため、以下の確認できた情報をもとに設計しています。
- リネットは2019年度グッドデザイン賞を受賞しており、審査講評では「クリーニングをアプリ・Webで数クリック完結できるようリデザインした」「面倒なものを気持ちよい体験に変えた」という利便性・わかりやすさが評価されています（出典：[eczine](https://eczine.jp/news/detail/7091)、[ホワイトプラス プレスリリース](https://www.wh-plus.co.jp/2019/10/pr-20191002/)）
- 宅配クリーニング系サービスLPで一般的な、清潔感を伝える水色×白の配色、数字付きの「利用の流れ」ステップ、シンプルな会員登録・申込導線という構成の型を採用しています

**南洋舎クリーニングは実店舗型（来店・お預け）であり、リネットのような宅配・アプリ注文サービスがある店舗ではないことが未確認です。** そのためリネットのデザイン言語（配色・レイアウトの型）は取り入れつつ、「ご利用の流れ」は宅配ではなく実際の来店フローとして構成しています。

- **配色** — 白地に、清潔感を感じさせる水色（`--sky`）をメインカラーに。CTAボタンには対比のはっきりする珊瑚色（`--coral`）を使用し、行動を誘導
- **ヘッダー** — 浮遊型のグラスパネルナビをやめ、上部固定の一般的な白いナビバーに変更
- **ヒーロー** — 実店舗の写真がないため、シンプルな線画イラスト（衣類のクリーニングを示すアイコン風グラフィック）を配置。写真を軸にしたリネットの見せ方とは異なりますが、宅配サービスと誤解されないよう配慮しています
- **信頼バッジ帯** — ヒーロー直下に確認済みの強み（シミ抜き対応・手仕上げ・組合加盟・エリア）を横並びで表示
- **ご利用の流れ** — 番号付きの3ステップ（お電話でご相談→ご来店・お預け→仕上がり・お渡し）を、点線でつないだタイムライン風に表示
- **選ばれる理由** — 均等な4カラムのアイコンカードに変更（初版の非対称ベントーグリッドから、より一般的な整列レイアウトへ）
- **実績バナー** — 「杉並区技能功労者表彰」を水色の帯バナーで紹介
- **スクロール演出** — IntersectionObserverによるフェードインは維持（JS無効時・reduced motion環境ではアニメーションなしで即時表示）

## 構成

ヒーロー／信頼バッジ帯／ご利用の流れ（3ステップ）／選ばれる理由（4カード）／実績バナー（技能功労者表彰）／アクセス・店舗情報／よくある質問4問／クロージングCTA。料金・集荷宅配サービスの有無が未確認のため、料金セクションと集荷・お届けセクションは含めていません。

## 差し替えるところ

- 営業時間・定休日（`#access` の案内板、および `.caution` の注記）
- 料金（現状は「お電話でご相談ください」導線のみ）
- 駐車場・支払い方法・宅配サービスの有無
- フッターの注意書き・名称注記（実店舗確認後に削除）
- 可能であれば実店舗の外観写真（ヒーローのイラストと差し替え可能）

配色を変える場合は `:root` の `--sky` / `--coral` / `--mint` を書き換えれば全体に反映されます。
